# FFmpeg Corresponding Source

Complete corresponding source for the unmodified FFmpeg binaries we ship
(GPL build, including libx264 and libx265).

See [Releases](../../releases) for downloadable source archives.
See `BUILD.txt` for the exact version, commit, and configure line of each build.

## Why this repo exists

Those binaries are compiled with `--enable-gpl`. The GNU General Public License
requires that the complete corresponding source for the exact builds we
distribute is available, free of charge. This repository is that source.

Desktop apps that ship these binaries link here from Settings → About →
Open Source Licenses.
